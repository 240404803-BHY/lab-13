## Proje Açıklaması

Bu proje, React Native (Expo) kullanılarak geliştirilmiş çok ekranlı bir mobil uygulamadır.  
Uygulama; Expo API’leri aracılığıyla cihazın donanım özelliklerini kullanarak kamera ve galeri erişimi, konum (GPS) alma, yerel bildirim gönderme ve dokunsal geri bildirim (Haptics) gibi işlevleri kullanıcı izinleri ile birlikte güvenli şekilde gerçekleştirir.

Bu laboratuvar çalışması aşağıdaki konuları kapsamaktadır:
- Kamera ve galeri erişimi
- Konum (GPS) erişimi
- Yerel bildirimler
- Dokunsal geri bildirim (Haptics)
- İzin yönetimi (permission flow)
- Asenkron yerel API çağrıları
- Uygun yaşam döngüsü temizliği (cleanup)
